# Confluence Scanner

A cryptocurrency market scanner built with Java and Spring Boot.

## Features

- Binance Futures market data
- Bitunix symbol filtering
- Higher Timeframe Bollinger Bands
- Heiken Ashi analysis
- BB Width ranking
- Multi-Timeframe confluence detection

## Tech Stack

- Java 17
- Spring Boot
- Maven
- REST API

## Roadmap
